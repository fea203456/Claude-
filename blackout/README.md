# «БЛЭКАУТ. Эпизод 01» — блок «Катастрофы»

Серьёзный триллер-выживание в плоской тёмной графике. Сделан по принципам из `../ideas/blok-katastrofy.md`
(разбор референса), но со своей историей, героями и картинкой.

**Идея.** «Если в твоём городе погас свет, ты живёшь в самом умном доме. Но у него есть одна слабость — розетка».
Марк на 21-м этаже ждёт сына. Тим (9 лет) едет в лифте. В 18:03 гаснет весь город, лифт встаёт между 14-м и 15-м.
Сети нет, вода уходит с верхних этажей, а электронный замок без питания не открыть. Механический ключ лежит в машине на минус втором.

| Файл | Содержание | Длина |
|---|---|---|
| `out/blackout-ep01-part1.mp4` | Крючок, карточки-факты, «розетка», 18:02 → 18:03, лифт встал | 25,7 с |
| `out/blackout-ep01-part2.mp4` | Правила №1–3 (заряд, вода, лифт), звонок: гудки → вызов прерван → сети нет, «умный дом оглох» | 29,7 с |
| `out/blackout-ep01-part3.mp4` | 21:40 → 21:55: замок молчит, стук соседки, ключ на −2, сплит «Марк заперт / Тим ждёт» | 24,6 с |
| `out/cover-part1.jpg` … `cover-part3.jpg` | Обложки 1080×1920 | — |

Формат: 1080×1920, 60 кадров/с, H.264 + AAC. Закадрового голоса нет (в среде нет ключа озвучки): субтитры, музыка и шумы.

## Приёмы из блока «Катастрофы»

- обращение на «ты» и перевёрнутое обещание в первые секунды;
- лестница ухудшений: каждая строка субтитров — одна ступень хуже;
- таймкод в углу, интервалы сжимаются: 18:02 → 18:03 → 18:20 → 21:40 → 21:52 → 21:55;
- чередование «история → правило → история», плашки «ПРАВИЛО №N» со схемами (телефон, разрез дома);
- одна метафора с перевёртышем: значок связи над домом → перечёркнутый;
- ключевое слово жёлтым (важное) или красным (угроза), красная вспышка и удар на угрозе;
- финал-обрыв каждой части и сплит «внутри / в лифте» в конце.

## Устройство

- `src/script.js` — сценарий: строки субтитров с длительностью, сценой, эффектом, таймкодом и звуком. Картинка и звук читают один файл.
- `src/art.js` — палитра, плоские персонажи, город, разрез дома, телефон.
- `src/film.js` — сцены, субтитры, плашки, обложки.
- `src/lib.js` — движок (камера с параллаксом слоёв, DOF, motion blur подкадрами), общий с серией «Что будет, если…».
- `tools/audio.py` — синтез звука: гул сети до блэкаута, сердцебиение после, шумы на каждую строку.
- `tools/render.js` — покадровый рендер через Playwright.

## Пересборка

```bash
python3 tools/audio.py
node tools/render.js b1 build/b1 0 1542 4
ffmpeg -framerate 60 -i build/b1/f%05d.jpg -i out/b1_mix.wav -af loudnorm=I=-14:TP=-1.5:LRA=11 \
  -c:v libx264 -preset slow -crf 20 -pix_fmt yuv420p -r 60 -c:a aac -b:a 192k -ar 48000 -movflags +faststart out/blackout-ep01-part1.mp4
node tools/render.js c1 --stills out 0   # обложка
```

Части 2 и 3: `b2` (1782 кадра) и `b3` (1476 кадров).

## Оговорка

«Правила» в ролике — сюжетный приём, а не инструкция по безопасности. Про воду и замки сказано в рамках истории
этого дома; в реальных домах всё зависит от конкретных систем.
