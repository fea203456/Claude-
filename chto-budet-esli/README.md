# «Что будет, если нажать „ещё 5 минут“?» — мультсериал с выбором зрителя

Три вертикальных ролика (1080×1920, 60 fps, H.264 + AAC) в мультяшной 2.5D-рисовке.

| Файл | Часть | Длина |
|---|---|---|
| `out/part1-vybor.mp4` | Завязка: 7:00, будильник Дзынь, рука тянется к кнопке → **СТОП** → «А — встать / Б — ещё 5 минут? Пиши в комментах» | 18 с |
| `out/part2-variant-A.mp4` | Вариант А: встал, потянулся, открыл шторы, тост на лету, «7:20 — времени полно» | 16 с |
| `out/part3-variant-B.mp4` | Вариант Б: «ещё 5 минут» × 8 → «7:40?!» → сборы бегом через весь дом → автобус уходит из-под носа | 20 с |

Части 2 и 3 начинаются с того же стоп-кадра, на котором заканчивается часть 1, поэтому серия смотрится непрерывно.

- `storyboard.md` — раскадровка: варианты для каждой сцены и выбранное решение.
- `../ideas/chto-budet-esli.md` — банк идей для следующих серий в том же формате.
- `src/` — Canvas 2D без фреймворков. `lib.js` (камера с параллаксом слоёв, DOF, motion blur усреднением подкадров, риг персонажей), `scenes.js` (спальня → кухня → улица), `part1..3.js`, `cues.js` (общий тайминг картинки и звука).
- `tools/audio.py` — синтез музыки и SFX по `cues.js` (без сэмплов) → `out/pN_mix.wav`.
- `tools/render.js` — покадровый детерминированный рендер через Playwright.
- Шрифты: Rubik и Pangolin (SIL OFL, лицензии в `src/fonts`).

## Пересборка

```bash
python3 tools/audio.py
node tools/render.js 1 build/p1 0 1080 4
ffmpeg -framerate 60 -i build/p1/f%05d.jpg -i out/p1_mix.wav -af loudnorm=I=-14:TP=-1.5:LRA=11 \
  -c:v libx264 -preset slow -crf 22 -pix_fmt yuv420p -r 60 -c:a aac -b:a 192k -ar 48000 -movflags +faststart out/part1-vybor.mp4
```

Для частей 2 и 3: кадры `0 960` и `0 1200`. Предпросмотр: открыть `src/index.html?part=2` в браузере.
