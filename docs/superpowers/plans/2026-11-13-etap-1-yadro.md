# Этап 1: ядро игры — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Игрок управляет героем на тестовом участке фермы, видит смену дня и ночи, ложится спать (автосохранение), выходит и продолжает с того же места; сохранения версионируются и мигрируют.

**Architecture:** Три сервиса-узла (`GameClock`, `SaveService`, `GameFlow`) подключаются как autoload, но каждый — обычный класс (`class_name`), который тесты создают напрямую. Системы отдают в сохранение свой раздел через `to_save()/from_save()`; ядро сохранений не знает их внутренностей. Свет суток — ресурс-кривая + применитель. Герой — `CharacterBody3D`, движение относительно `CameraRig`.

**Tech Stack:** Godot 4.5.1 (Forward+, GDScript), headless Blender 5.0.1 (`bpy`) для дома и кровати, pytest; Xvfb + lavapipe для скриншотов.

**Spec:** `docs/superpowers/specs/2026-11-13-etap-1-yadro-design.md` (общая: `docs/superpowers/specs/2026-11-13-uvyadayushchiy-krai-design.md`)

## Global Constraints

- Всё из Global Constraints этапа 0 остаётся в силе (`docs/superpowers/plans/2026-11-13-etap-0-konveyer-npc.md`): Godot 4.5.1 Forward+, glb, +Z вперёд в Godot, палитра `tools/blender/lib/palette.py`, оригинальные ассеты.
- Тесты: `tools/godot.sh test` (раннер `game/tests/run_tests.gd`: методы `test_*() -> String`, `""` = PASS; любая ошибка движка во время теста = FAIL) и `tools/blender.sh -m pytest tools/blender/tests -q`. Оба зелёные в конце каждой задачи.
- Тесты создают классы напрямую и не полагаются на autoload; дерево — `(Engine.get_main_loop() as SceneTree).root`; добавленные узлы освобождаются.
- Время: **1 игровая минута = 1 реальная секунда** при `speed = 1.0`; активные сутки 06:00–02:00; ночь с 20:00; спать можно с 18:00; 4 сезона × 28 дней.
- Время хранится как `minutes` — **целые игровые минуты от 06:00 текущего дня**, 0…1200 (1200 = 02:00). Часы на циферблате: `(360 + minutes) % 1440`.
- Сохранение: `user://save/slot_1.json`, `SAVE_VERSION = 1`, атомарная запись (tmp → rename), предыдущее — `.bak`.
- Ходьба 1.40 м/с (из `extras.stride_m` модели), бег ×1.8; камера 45° вниз, дистанция 6–14 м (по умолчанию 8), поворот шагами 45° за 0.25 с; радиус взаимодействия 1.5 м.
- Все тексты UI — через ключи перевода `tr("KEY")`, таблица `game/locale/strings.csv` (колонки `keys,ru,en`); язык по умолчанию `ru`.
- Сообщения коммитов на русском, с трейлерами сессии.

## Review Focus

1. **Большой кадр (зависание, alt-tab, 10+ с за кадр)** не должен пропускать события: `advance(1300.0)` одним вызовом даёт ровно один `night_started`, ровно один `collapsed` и день 2. → `test_big_delta_does_not_skip_events` (Task 1).
2. **Выход в 01:59 и «Продолжить»** — обморок в 02:00 всё равно случается. → `test_collapse_after_load_at_0159` (Task 1).
3. **Нет папки сохранений / запись не удалась** — папка создаётся; неудачная запись не портит существующее сохранение. → `test_creates_save_dir`, `test_failed_write_keeps_old_save` (Task 2).
4. **Диагональный ввод** не быстрее прямого. → `test_diagonal_not_faster` (Task 3).
5. **Выход из игры с открытой паузой** сохраняет точное состояние, время на паузе не шло. → `test_quit_from_pause_saves_exact_state` (Task 8).
