# Этап 2: ферма — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Игрок вскапывает клетки поля, сажает три культуры, поливает, после сна видит рост и собирает урожай; земля устаёт; поле и инвентарь сохраняются.

**Architecture:** Чистые данные и логика — `Inventory` и `FarmState` (RefCounted, без дерева сцены), правила кнопки E — `FarmActions`. Ими владеет `GameFlow`: создаёт на каждый мир, регистрирует в `SaveService`, считает ночь по `day_started`. Узлы сцены (`FarmField`, `FarmInteractor`, `Well`, `Hotbar`) только показывают состояние и передают ввод. Контент — ресурсы `.tres` (`ItemDef`, `CropDef`) в `game/data/`, в сохранении только строковые `id`.

**Tech Stack:** Godot 4.5.1 Forward+ (GDScript), Blender 5.0 `bpy` (headless, `tools/blender.sh`), pytest, ffmpeg.

**Spec:** `docs/superpowers/specs/2026-11-14-etap-2-ferma-design.md`

## Global Constraints

- Тесты Godot: `tools/godot.sh test`; `test_*() -> String`, `""` = PASS; **любая ошибка движка в логе = FAIL**, предупреждения допустимы. Тесты создают свои `GameClock` / `SaveService` / путь сохранения, autoload не трогают.
- Тесты Blender: `tools/blender.sh -m pytest tools/blender/tests -q`; glb импортируются с `disable_bone_shape=True`.
- Модели: low-poly, плоское затенение, только материалы из `tools/blender/lib/palette.py` (новые цвета добавляются туда, sRGB); в Godot +Z вперёд = −Y в Blender; начало координат — центр основания на земле.
- Цвета в `.tres` / `.tscn` — sRGB.
- Все тексты игрока — ключи в `game/locale/strings.csv` (`keys,ru,en`), обе колонки непустые.
- Время — только `GameClock`; ночной расчёт фермы — только из обработчика `day_started`. Сохранение — только через `SaveService` (раздел + миграция).
- Герой (`PlayerController`), камера (`CameraRig`) и правило досягаемости `InteractionProbe` (1.5 м, конус 60°) не меняются.
- Числа из спеки: поле `Rect2i(-6, 2, 12, 8)` (клетки x −6…5, z 2…9); 8 ячеек; стопка 99, инструменты по 1; лейка 10; порог плодородия 60; восстановление +3 до 60; множитель урожая 0.5…1.
- Неизвестный `id` — `push_warning`, не `push_error`.

## Review Focus

1. **Испорченное или отредактированное сохранение** — массив ячеек не из 8 элементов, числа пришли как `3.0`, `count` 0 / отрицательный / > 99, плодородие вне 0…100, две записи одной клетки, клетка вне поля, `null` вместо словаря. Ожидание: загрузка без ошибок, значения зажаты в границы, остальные записи не потеряны. → `test_from_save_tolerates_garbage` (Task 5 и Task 6).
2. **Сбор при почти полном инвентаре** — урожай помещается, семена нет. Ожидание: не собрано ничего, растение на месте, подсказка «Нет места». → `test_harvest_is_atomic` (Task 8).
3. **Клетки с отрицательными координатами** — точка x = −0.5 принадлежит клетке −1, не 0. → `test_cell_at_negative` (Task 9).
4. **Ночь считается ровно один раз** — сон, обморок, загрузка, новая игра после выхода в меню. Ожидание: рост один раз за `day_started`, в автосохранении уже выросшее поле, загрузка не растит, новая игра не наследует поле и инвентарь прошлой. → `test_night_once_*`, `test_new_game_resets_farm` (Task 7).
5. **Неизвестные `id` при круговом сохранении** — загрузили файл с неизвестным предметом и культурой, поиграли, сохранили. Ожидание: записи на месте дословно, `add()` не занимает ячейку с неизвестным предметом, на клетку с неизвестной культурой нельзя сажать/поливать/собирать. → `test_unknown_ids_roundtrip` (Task 5, 6), `test_unknown_crop_cell_inert` (Task 8).

### Task 6: Состояние поля — клетки, рост, усталость

**Files:** Create `game/scripts/farm/farm_state.gd`, `game/tests/test_farm_state.gd`

**Interfaces — Consumes:** `ContentDB`, `CropDef` (Task 4).
**Produces:** `FarmState extends RefCounted`:
- `signal changed()`; `var db: ContentDB`; `var bounds := Rect2i(-6, 2, 12, 8)`.
- `in_field(cell: Vector2i) -> bool`, `is_tilled(cell) -> bool`, `cells() -> Array[Vector2i]`, `plot(cell) -> Dictionary` (копия; `{}` если не вскопана; поля `fertility: float`, `watered: bool`, `crop: String`, `growth: float`).
- `till(cell) -> bool` (в поле и не вскопана; плодородие 100), `plant(cell, crop_id) -> bool` (вскопана, пусто, культура известна), `water(cell) -> bool` (вскопана, не полита, культура не неизвестна).
- `has_plant(cell)`, `is_unknown(cell)` (культура не найдена в базе), `stage(cell) -> int` (0…3; −1 без растения или неизвестная), `is_ripe(cell) -> bool`.
- `harvest(cell) -> Dictionary`: `{}` если не спелое; иначе `{"crop": id, "produce": int, "seeds": int}`, клетка становится пустой вскопанной, плодородие −`fatigue` (не ниже 0).
- `advance_night()`: порядок **рост → восстановление → сухо**. Рост: политая клетка с известной культурой `growth += growth_rate(fertility)`. Восстановление: пустая клетка с `fertility < 60` → `min(60, fertility + 3)`.
- `static func growth_rate(fertility: float) -> float` — `1.0` при ≥ 60, иначе `0.5 + 0.5 * fertility / 60`.
- `static func yield_for(base: int, fertility: float) -> int` — `max(1, floor(base * (0.5 + 0.5 * fertility / 100)))`.
- Стадия: по `growth` и накопленным суммам `stage_days` с допуском `1e-6`; спелое при `growth ≥ total_days()`.
- `clear()`; `to_save()` = `{"plots": [{"x","z","fertility","watered","crop","growth"}, …]}`; `from_save(d)`. Запись с неизвестной культурой хранится и отдаётся дословно.

### Task 7: Сохранение v2 и подключение к игровому циклу

**Files:** Modify `game/scripts/core/save_service.gd` (`SAVE_VERSION := 2`), `game/scripts/core/save_migrations.gd`, `game/scripts/core/game_flow.gd`, `game/tests/test_save_service.gd`, `game/tests/test_game_flow.gd`

**Interfaces — Consumes:** `Inventory` (Task 5), `FarmState` (Task 6), `ContentDB.load_default()` (Task 4).
**Produces:**
- `SaveMigrations.STEPS = {1: v1_to_v2}`; `static func v1_to_v2(data: Dictionary) -> Dictionary` добавляет `"farm": {"plots": []}` и `"inventory": Inventory.starter_save()`, остальное не трогает.
- `GameFlow`: `var db: ContentDB`, `var inventory: Inventory`, `var farm: FarmState` — создаются заново в `attach_world` (у обоих `db`), регистрируются как `"inventory"` и `"farm"`, снимаются и обнуляются в `detach_world`.
- `attach_world` раздаёт по именам узлов (отсутствующие пропускает): `FarmField` и `FarmInteractor` ← `state = farm`; `FarmInteractor`, `Well`, `Hotbar` ← `inventory`; все четыре ← `db`.

### Task 8: Правила кнопки E — действия на клетке

**Files:** Create `game/scripts/farm/farm_actions.gd`, `game/tests/test_farm_actions.gd`; Modify `game/locale/strings.csv`

**Interfaces — Consumes:** `FarmState`, `Inventory`, `ContentDB`.
**Produces:** `FarmActions extends RefCounted`, статические:
- `resolve(state: FarmState, inv: Inventory, cell: Vector2i) -> Dictionary` = `{"kind": StringName, "reason": StringName, "text": String}`; ничего не меняет. `kind` ∈ `&"harvest"`, `&"plant"`, `&"water"`, `&"till"`, `&"none"`. Первое подходящее правило:
  1. спелое растение → `harvest`; если `inv.can_add_all([[produce, n], [seed, m]])` ложно → `none` / `&"no_room"` / `PROMPT_NO_ROOM`;
  2. вскопана, пусто, в руке семя известной культуры → `plant` / `PROMPT_PLANT_FMT` с `{crop}`;
  3. вскопана, культура не неизвестна, в руке лейка → полита: `none` / `&"already_watered"`; `can_water == 0`: `none` / `&"can_empty"`; иначе `water`;
  4. в руке мотыга → клетка в поле и не вскопана: `till`; вне поля: `none` / `&"cant_till"`;
  5. неспелое растение → `none` / `&"growing"` / `PROMPT_GROWING_FMT` с `{crop}`, `{stage}`; неизвестная культура → `none` / `&"unknown"` / `PROMPT_UNKNOWN_PLANT`;
  6. иначе `none`, `text == ""`.
  Для вскопанной клетки к `text` добавляется строка `SOIL_FMT` (`"\n"` между, если основной текст не пуст); процент — округлённое целое.
- `perform(state, inv, cell) -> StringName` — выполняет то, что вернул `resolve`, возвращает `kind`. `plant` снимает 1 семя из выбранной ячейки; `water` — `inv.use_water()`; `harvest` — `state.harvest` + `inv.add` урожая и семян.
- Ключи: `PROMPT_TILL` «E — вскопать» / «E — till», `PROMPT_PLANT_FMT` «E — посадить: {crop}» / «E — plant: {crop}», `PROMPT_WATER` «E — полить» / «E — water», `PROMPT_HARVEST` «E — собрать» / «E — harvest», `PROMPT_CAN_EMPTY` «Лейка пуста» / «The can is empty», `PROMPT_ALREADY_WATERED` «Уже полито» / «Already watered», `PROMPT_CANT_TILL` «Здесь нельзя копать» / «Can't dig here», `PROMPT_NO_ROOM` «Нет места» / «No room», `PROMPT_GROWING_FMT` «{crop} — {stage}», `PROMPT_UNKNOWN_PLANT` «Неизвестное растение» / «Unknown plant», `SOIL_FMT` «Земля: {pct}%» / «Soil: {pct}%».
