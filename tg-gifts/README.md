# Монитор маркета подарков Telegram

Следит за встроенным маркетом подарков и присылает алерты. Только читает данные:
ничего не покупает, не продаёт и не переводит.

## Что присылает

| Алерт | Когда срабатывает |
|---|---|
| 🎯 Лот дешевле соседних | Самый дешёвый лот ниже медианы трёх следующих настолько, что после комиссии (20% за Stars, 10% за TON) остаётся от `min_profit_pct` прибыли |
| 💎 Редкий атрибут у флора | Модель или фон с редкостью до `rare_permille` ‰ стоит не дороже флора + `rare_over_floor_pct` % |
| 📉 Флор упал | Флор ниже медианы за последние сутки на `floor_drop_pct` % и больше |
| 🆕 Новый подарок | В каталоге появился подарок, которого раньше не было |

## Запуск

Нужен Python 3.10+ и свой компьютер или сервер: монитор входит в твой аккаунт Telegram.

```bash
cd tg-gifts
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

# ключи приложения: https://my.telegram.org → API development tools
export TG_API_ID=123456
export TG_API_HASH=0123456789abcdef0123456789abcdef

python monitor.py --list    # первый запуск спросит телефон и код; покажет флор по подаркам
python monitor.py           # цикл: проход каждые 5 минут
```

Алерты приходят в «Избранное». Чтобы приходили с уведомлением, создай бота у @BotFather,
напиши ему `/start` и задай `TG_BOT_TOKEN` и `TG_ALERT_CHAT_ID` (свой числовой id).

Настройки: скопируй `config.example.json` в `config.json`. В `watchlist` — точные названия
подарков, как в `--list`. Если список пуст, монитор берёт самые ликвидные подарки с флором
до `max_floor_stars`.

## Безопасность

- Файл `monitor.session` — это вход в твой аккаунт. Никому не передавай и не коммить (он в `.gitignore`).
- `TG_API_HASH` и токен бота держи только в переменных окружения.
- Не уменьшай `interval_sec` и `request_pause_sec`: частые запросы с личного аккаунта ведут к FloodWait и ограничениям.
- Для спокойствия можно завести отдельный аккаунт под монитор: ему нужен только доступ на чтение маркета.

## Ограничения

- Видит только встроенный маркет Telegram. У Portals, Tonnel и MRKT нет официального публичного API,
  поэтому их цены сверяй вручную перед сделкой.
- Алерт — повод посмотреть лот, а не сигнал купить. Опорная цена считается по трём соседним лотам;
  в тонком стакане она ненадёжна.
- Комиссии зашиты в `analyze.py` (`FEE_STARS`, `FEE_TON`). Если Telegram их изменит, поправь там.
