# TgMod Desktop

Telegram-клиент для компьютера на основе [tweb (Telegram Web K)](https://github.com/morethanwords/tweb),
упакованный в Electron. Устроен так же, как Duckgram, но со своим оформлением.

Мод хранится не форком, а набором изменений поверх конкретного коммита tweb
(записан в `UPSTREAM_COMMIT`).

| Путь | Что это |
|---|---|
| `overlay/` | Новые файлы мода, копируются в дерево tweb как есть. |
| `patches/` | Минимальные врезки в существующие файлы tweb. |
| `apply.sh` | Накладывает overlay и патчи на чистый checkout tweb. |
| `electron/` | Оболочка для Windows/Linux: трей, горячая клавиша, бейдж, заставка, обход блокировок. |
| `scripts/assemble-app.js` | Собирает каталог веб-клиента для оболочки. |
| `build.sh` | Полная сборка с нуля. |

## Возможности

- **Темы:** «Неон» (по умолчанию), AMOLED, «Стекло», «Закат», «Мята» и стандартная.
  Палитра идёт через движок тем tweb, у «Неона» и «Заката» градиентные пузыри сообщений.
- **Режим призрака:** раздельно скрывает «в сети», отметки о прочтении, «печатает…» и просмотры историй.
- **ID в профилях** включён по умолчанию.
- **Свой звук уведомлений:** MP3/OGG/WAV до 1 МБ, хранится только на устройстве.
- **Обход блокировок** (только десктоп): если прямое подключение не работает, приложение ищет
  адрес Telegram через DNS-over-HTTPS и перебор официальных диапазонов Telegram, проверяет его
  TLS-рукопожатием с настоящим сертификатом Telegram и направляет `*.web.telegram.org` на него.
  Системный `hosts` не меняется, права администратора не нужны, прокси и VPN не используются.
- **Десктоп:** иконка в трее, закрытие в трей, `Ctrl+Alt+M` — показать/скрыть, бейдж непрочитанных
  на иконке в панели задач, заставка, один экземпляр, ссылки открываются в браузере.
- **Русский язык:** строки мода переведены, остальное — из официального пакета Telegram.

Все настройки: **Настройки → Настройки мода**.

## Сборка

```bash
tgdesk/build.sh win     # портативный .exe и .zip в tgdesk/electron/release
tgdesk/build.sh linux   # AppImage
```

Windows-версия собирается и на Linux: подпись и правка ресурсов `.exe` отключены, поэтому у самого
`.exe` пока стандартная иконка Electron (у окна и трея — своя).

### API-ключи

По умолчанию используются публичные ключи, которые tweb кладёт в свой `.env` для самостоятельных
сборок. Свои ключи с <https://my.telegram.org> можно положить в `.work/tweb/.env.local`:

```
VITE_API_ID=12345
VITE_API_HASH=0123456789abcdef0123456789abcdef
```
