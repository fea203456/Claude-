# TgMod — промо-ролик: раскадровка

**Нить:** мыльный пузырь, фирменный приём мода, ведёт зрителя по функциям. Пузырь лопается и открывает
название, превращается в карточки тем, «призрачно» гасит статусы, несёт уведомление и находит путь
сквозь блокировку, а в конце все пузыри собираются в иконку.

**Формат:** 1920×1080, 60 fps, 37 с, H.264 + AAC. Музыка 120 BPM (такт = 2 с), синтезирована в `scripts/audio.py`.
Заголовки — Unbounded (OFL), интерфейс — Inter. Кадры интерфейса — настоящий TgMod из песочницы tweb
(`assets/ui`, снято `scripts/capture-ui.js`); окно чата, панель режима призрака и схема сети — иллюстрации.

**Риск, проверенный пробой:** CSS 3D + canvas в headless Chromium при 1920×1080 рендерятся
детерминированно по `renderAt(t)` (кадры снимаются Playwright, 120 кадров/с с усреднением пар → 60 fps
с лёгким motion blur).
